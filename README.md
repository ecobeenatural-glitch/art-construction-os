# ART Construction OS

ART Construction OS is an AI-powered platform that automates the entire apartment renovation workflow.

## Vision

From a developer's PDF floor plan to:

- BIM model (Revit)
- Interior design
- Material estimation
- Cost calculation
- Construction planning
- Business analytics

## Modules

- art-converter
- art-bim
- art-estimate
- art-ai
- art-api
- art-dashboard

## Technology

- Python
- OpenCV
- AI
- Revit API
- FastAPI
- PostgreSQL
- Power BI
